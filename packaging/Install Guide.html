BJJ FPS Limiter

Locks your game to a smooth 60 FPS.

A bjj_dev product · built for NightZoom

How to install

  1. Open your FiveM plugins folder.

    Press Win+R, paste this, press Enter: 
    %localappdata%\FiveM\FiveM.app\plugins
    A folder window opens - leave it open.

    Nothing opened / error? Then FiveM isn't in the default spot. Open your FiveM install folder instead (the one with FiveM.exe) and go into FiveM.app\plugins inside it.

  2. Drag the add-on files into that folder.

    In the zip, open the Copy-these-into-plugins folder. Drag its three files - dxgi.dll, BJJ-FPS-Limiter.addon64, Enable-ReShade.bat - into the plugins folder.

    Already have ReShade? (NVE, QuantV, other graphics pack)

    Don't drag dxgi.dll - that is ReShade, and you already have it. Just drag the other two files and leave your existing ReShade completely alone.

    ReShade can be installed under a few different file names (dxgi.dll, d3d11.dll and others) - whichever yours uses, you don't need to touch it.

    Upgrading from the old NightZoom FPS Limiter?

    Delete NZ-FPS-Limiter.addon64 from the plugins folder. The add-on was renamed in v3.0.0, so the old file won't be overwritten - and ReShade runs every add-on it finds. Two limiters pacing the same frame caps you at about 30 FPS instead of 60.

    Your on/off setting carries over on its own - you don't need to set anything up again.

    Drag the files themselves, not the folder - all three should sit directly inside the plugins folder, not inside a sub-folder.

  3. Allow ReShade in FiveM (one time).

    In the plugins folder you just filled, double-click Enable-ReShade.bat. It sets everything up by itself - press a key to close it.
    • Blue "Windows protected your PC" box? Click More info → Run anyway. (It's open source - open it in Notepad first if you like.)
    • Says it couldn't find FiveM? See If the .bat can't find FiveM below.

  4. Start FiveM and join the server.

  5. Turn the limiter ON.

    Press Home to open the ReShade menu. (Some setups use Insert instead - if Home does nothing, try Insert.) First time, ReShade shows a tutorial pop-up: click Continue or Skip Tutorial. Find the "BJJ FPS Limiter" window and tick Limit to 60 FPS.

    ✓ Done - your choice is saved for next time.

Why 60 FPS?

GTA's physics is tied to your frame rate - higher FPS can change how a car behaves. On a racing server that's unfair: people on stronger PCs would get an edge. Capping everyone to 60 FPS keeps the physics consistent so nobody has an advantage.

Already have ReShade but don't see the window?

Good news: you almost certainly don't need to replace anything. This add-on works with any ReShade from 6.1 onwards, which covers current graphics packs. Just make sure BJJ-FPS-Limiter.addon64 is sitting in your plugins folder and leave the rest of your setup exactly as it is.

If the "BJJ FPS Limiter" window still doesn't show up, first make sure you tried Home and Insert, then open ReShade.log in your FiveM.app folder and look near the top for a line like:

Failed to register add-on, because the requested API version (11) is not supported (N)!

That means your ReShade is older than 6.1. The best fix is to update your graphics pack - current versions ship a recent ReShade, and that keeps everything else about your setup intact.

If you'd rather update ReShade by hand: Important - ReShade isn't always called dxgi.dll. Depending on how it was installed the file may be named dxgi.dll, d3d11.dll, d3d12.dll, d3d9.dll or opengl32.dll. Look in your plugins folder to see which one you have.

Then take the zip's dxgi.dll (from the Copy-these-into-plugins folder), copy it into your plugins folder and rename it to match the file you already have, replacing it. Renaming matters: dropping a dxgi.dll next to an existing d3d11.dll does nothing, because the old one still loads first. It's the latest official ReShade and still runs graphics packs fine.

Back up the file you're replacing first, so you can put it back if anything misbehaves.

If the .bat can't find FiveM (manual allow)

Only needed if Enable-ReShade.bat couldn't locate FiveM. The first time you launch with ReShade, FiveM's console shows red text like:

Blocked load of ReShade version 5 or higher ...
add the following section to <path>\CitizenFX.ini:
   [Addons]
   ReShade5=ID:xxxxxxxx acknowledged that ReShade 5.x has a bug...
  1. Fully close FiveM.
  2. Open the file it named - CitizenFX.ini, in your FiveM.app folder (the console shows the exact path).
  3. Add the two lines exactly as your own console showed them: 
    [Addons]
ReShade5=ID:xxxxxxxx acknowledged that ReShade 5.x has a bug that will lead to game crashes
    The ID (xxxxxxxx) is unique to your PC - copy it from your own console, not this example.
  4. Save and start FiveM again.

How to use

  • Press Home (or Insert) to open/close the ReShade menu.
  • In the "BJJ FPS Limiter" window: tick Limit to 60 FPS to cap, untick to unlock instantly.
  • Your choice is saved and stays set next launch.
  • Turn VSync off in-game. The limiter and VSync each wait for their own timing, and running both together can stack those waits into stutter or an effective 30 FPS. Use one or the other - this add-on instead of VSync.

How to uninstall

  1. Close FiveM.
  2. Open %localappdata%\FiveM\FiveM.app\plugins.
  3. Delete BJJ-FPS-Limiter.addon64 (and NZ-FPS-Limiter.addon64, if an older install left one behind).
  4. Only if you installed ReShade just for this and want it gone too, also delete the ReShade file you added - dxgi.dll if you used our zip. If a graphics pack put ReShade there (under whatever name), leave it alone.

This add-on is made for the NightZoom server. On other servers, use it at your own risk - every server sets its own rules. If unsure, ask the server staff.
